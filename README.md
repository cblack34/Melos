# Melos

AI-powered music generation: creative prompts in, multi-track MIDI (with
embedded lyrics) out.

## Run

```bash
docker compose up --build
```

UI at <http://localhost:5173>, API at <http://localhost:8000>.

Docs: start at [`docs/features/semantic-composition/brief.md`](docs/features/semantic-composition/brief.md);
how-we-work lives in [`AGENTS.md`](AGENTS.md). The completed MVP specification is
archived under [`docs/archive/mvp/`](docs/archive/mvp/README.md).
