# Melos

AI-powered music generation: creative prompts in, multi-track MIDI (with
embedded lyrics) out.

## Run

```bash
docker compose up --build
```

UI at <http://localhost:5173>, API at <http://localhost:8000>.

Docs: start at [`docs/build-brief.md`](docs/build-brief.md); how-we-work lives
in [`AGENTS.md`](AGENTS.md).
